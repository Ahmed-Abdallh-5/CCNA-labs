Hands-on Cisco networking labs built while preparing for the CCNA. Each lab covers one topic: the network is built, configured on Cisco IOS, and then verified with show commands, ping/traceroute, and packet captures where relevant.

I'm a Junior SOC / Cybersecurity Analyst, so these labs also serve as my networking foundation for security monitoring: segmentation (VLANs), traffic filtering (ACLs), address translation (NAT), log time synchronization (NTP), and device monitoring (SNMP).

Tools: Cisco IOS · GNS3 · VMware Workstation · Wireshark
